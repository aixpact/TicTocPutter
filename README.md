# TicTocPutter

A putting stroke tempo oscillator. Every putt uses the same tic-toc tempo; only the length of the stroke changes with distance.

- **tic** at takeaway, **toc** at impact, with an optional double tic-toc that adds clicks at the top of the backstroke and the end of the follow-through.
- 2:1 tour rhythm or 1:1 pendulum rhythm, tempo from 56 to 112 BPM.
- Backstroke length worked out from distance, green speed (Stimp), slope and a personal feel adjustment.
- Animated face-on stroke over a cm/inch ruler, plus a ladder of stroke lengths per distance.

It is a single `index.html` with no build step. Open it in a browser, or turn on GitHub Pages (Settings → Pages → Deploy from branch `main`, folder `/`) to use it on your phone.

On iPhone the clicks play even with the silent switch on; the volume buttons still need to be up.
